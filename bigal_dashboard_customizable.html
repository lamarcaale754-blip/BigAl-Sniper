Switch product mode

Switching between BigAl Sniper and Rug Puller requires stopping the current session: the hunter orchestrator, Rust executor, and gRPC sidecar are terminated so the next mode can bind IPC and ports cleanly.

Enable auto-approve?

The orchestrator will mark new auto-generated honeypot plans as approved immediately, allowing Stage 4 deployment without your manual confirmation. This can spend real SOL in live mode.

Generate honeypot plan?

Builds a plan for this wallet immediately. Dashboard filters (age, auto-trigger threshold, ML confidence) do not apply. In live mode, if ML cannot produce a confident signature, a heuristic mock plan is still created for review.
